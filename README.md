# Kundalik+

Kundalik+ is an improvement layer built on top of [Kundalik](https://kundalik.com), the
widely-used Uzbek school platform — not a replacement for it. The goal is to fix
Kundalik's poor UI/UX while keeping the school–parent–student connection clear and
active.

## Roles

The platform has four separate logins / access levels, each with its own view and
permissions:

- **Principal** (директор)
- **Counsellor** (завуч)
- **Teacher**
- **Student**

Accounts start with simple, school-assigned default passwords. Students can later opt
to change their own password.

## Stack

- **Backend:** Django (Python)
